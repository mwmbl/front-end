# SvelteKit Frontend for Mwmbl

[SvelteKit](https://kit.svelte.dev/) (With Svelte 5) + [Bun](https://bun.sh/) + [Tailwind](https://tailwindcss.com/) + [shadcn-svelte](https://shadcn-svelte.com/)

## Developing

Make sure to have [Bun](https://bun.sh/) installed. If you use [mise](https://mise.jdx.dev/) a `.mise.toml` is included, and the correct version will be set up automatically.

```bash
bun install
bun dev

bun format # run before commit
```
